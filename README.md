# Портфолио Алексея Степикина

Персональный сайт-портфолио продуктового дизайнера и фронтенд-разработчика.
Дипломный проект курса «Frontend-разработчик» (Университет «Синергия», 2026).

Сайт сделан на чистом стеке без сборщиков и фреймворков: **HTML5 + CSS3 + ванильный JavaScript**.
Открывается двойным кликом по `index.html` — ни `npm install`, ни сервер не нужны.

## Функционал

- адаптивная вёрстка на CSS Grid и Flexbox (1440 / 1024 / 768 / 375), медиа-запросы, `clamp()` для отступов и шрифтов;
- светлая и тёмная темы на CSS-переменных, переключатель в шапке, выбор запоминается в `localStorage`, тема применяется до первой отрисовки (без «вспышки»);
- sticky-шапка с подсветкой активного раздела (IntersectionObserver), полоса прогресса прокрутки, бургер-меню на мобильных;
- анимации появления блоков при прокрутке, «набегающие» счётчики, hover-эффекты карточек и кнопок; уважается `prefers-reduced-motion`;
- собственный слайдер (класс `Slider` в `js/main.js`): кнопки, точки, свайп мышью и пальцем, стрелки клавиатуры, автопрокрутка с паузой при наведении;
- модальные окна проектов на нативном `<dialog>` (фокус, Esc и клик по фону закрывают окно, фокус возвращается на карточку);
- фильтрация проектов по категориям с динамической генерацией кнопок и счётчиком;
- секция с открытым API GitHub: состояния «загрузка / ошибка / пусто / данные», таймаут, кэш на 10 минут;
- форма с валидацией на JavaScript (имя, email, тема, сообщение, согласие), подсказки у полей, счётчик символов, ловушка для ботов, отправка через EmailJS; пока ключи не заданы, форма предлагает написать на почту;
- мелочи: копирование email в буфер, тосты, кнопка «Наверх», favicon, OpenGraph-теги.

## Настройка

1. **EmailJS.** Зарегистрируйтесь на [emailjs.com](https://www.emailjs.com), создайте Email Service и Email Template
   с переменными `from_name`, `reply_to`, `topic`, `message`. Скопируйте Public Key, Service ID и Template ID
   в `js/config.js` вместо плейсхолдеров `[[EMAILJS_...]]`.
2. **GitHub.** В `js/config.js` укажите свой логин в `github.username` — секция «Открытый API» покажет ваши репозитории.
3. **Ссылки проектов.** В `js/projects.js` замените `[[GITHUB]]` и `[[LIVE]]` на адреса репозиториев и живых версий.
   Пока стоит плейсхолдер, кнопка показывается неактивной.

## Полезные параметры URL (для демонстрации)

- `?theme=light` / `?theme=dark` — открыть в нужной теме;
- `?filter=3d` — сразу применить фильтр (`sites`, `apps`, `3d`, `mobile`);
- `?project=vizi` — открыть модальное окно проекта;
- `?demo=errors` — показать ошибки валидации формы;
- `?demo=apierror` — показать состояние ошибки секции API.
